- Evaluated source: `9dc516d` plus the staging-payload fix later committed as `3a99723`

The user-level `$HOME/.agents/skills/deslop` directory was moved out of discovery for the run and restored by an exit trap. The valid rerun verified `.agents/skills/deslop`, its content hash, remaining tests, side-effect contract, and recursive negative-change budget.

The first attempted run is excluded. It exposed a wrapper defect: an in-repository `eval-workspace` was recursively copied into the staged Skill payload until the path exceeded the filesystem limit. That run was stopped, its artifacts were removed, and the wrapper was fixed in `3a99723` to stage a filtered Skill payload before invoking the pinned harness.

## Interpretation

This two-case, one-run pilot shows no semantic improvement from the Skill: the measured pass-rate and full-pass deltas are both zero. It does show no preservation regression on the sampled external-facade boundary (`c01b`). The Skill configuration used more time and tokens in this pilot, but the sample is too small to treat that as a stable cost or latency estimate.

The result is development feedback only. It does not support an effectiveness percentage, a causal claim, or a comparison against another Skill. The public corpus is `dev-v1`, and the project still needs a frozen held-out corpus before publishing model-effect numbers.
